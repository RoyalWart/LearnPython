# Set Up Python and VS Code

No coding experience is needed. Install Python 3.10 or newer and an editor such as Visual Studio Code.

## Windows

1. Download Python from https://www.python.org/downloads/. Select **Add python.exe to PATH** in the installer.
2. Install Visual Studio Code from https://code.visualstudio.com/ and add the Microsoft Python extension.
3. In PowerShell or Command Prompt, run **python --version**; if needed, try **py --version**.
4. Create a folder named python-practice. Save a file called hello.py with:

~~~python
print('Hello, Python!')  # Display your first message.
~~~

5. Open a terminal in that folder and run **python hello.py** or **py hello.py**.

## macOS

1. Install Python 3 from python.org and check it with **python3 --version**.
2. Install Visual Studio Code and the Microsoft Python extension.
3. In Terminal, run **mkdir python-practice** and **cd python-practice**. Create hello.py with the example above.
4. Run **python3 hello.py**.

## Linux

1. Check **python3 --version**. If needed, use the package manager for your distribution to install Python 3.10 or newer.
2. Install Visual Studio Code or use an available editor.
3. Run **mkdir -p python-practice** and **cd python-practice**. Create hello.py with the example above.
4. Run **python3 hello.py**.

## If it does not run

- “Command not found”: restart the terminal and check installation/PATH.
- “File not found”: check the file name and current folder.
- A different version appears: try the python3 or py command available on your computer.

Do not paste commands you do not understand into a terminal. Ask a trusted adult or teacher if installation is blocked.
