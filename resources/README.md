## Debugging mini-guide
1. Read the **last line** of the error first. It says what went wrong.
2. The line number above it says where.
3. `print()` the variables near the problem.
4. Explain the code out loud, line by line (rubber duck debugging 🦆).
5. Search the exact error message.
