# Project: Number Guessing Game ⭐

The computer picks a secret number from 1 to 100. The player keeps guessing;
the game says "higher" or "lower" until they get it.

## Steps
1. Run `starter.py` and read the TODOs
2. Build it one step at a time. Run it after **each** step.
3. Commit to Git when each step works.

## Stretch goals
- Count the guesses and show them at the end
- Limit the player to 7 guesses
- Let the player choose the difficulty (range)
- Keep a high-score file (after lesson 04)
- Handle bad input like `"abc"` without crashing (after lesson 04)
