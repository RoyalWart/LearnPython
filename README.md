# 🐍 Learn Python by Doing

A hands-on Python course for teens (and anyone else!). You don't just read
about code, you write it, test it, break it, fix it, and share it, the way
real programmers do.

## How it works

Every lesson folder has the same pieces:

| File | What it's for |
|------|---------------|
| `README.md` | The lesson: read this first |
| `examples.py` | Runnable demos. Run them, change them, break them |
| `exercises.py` | Your turn! Fill in the functions |
| `test_exercises.py` | Automatic checker for your answers |
| `solutions.py` | Stuck? Peek here, but try first! |

**The loop:**
1. Read the lesson `README.md`
2. Run `examples.py` and play with it
3. Open `exercises.py` and replace each `raise NotImplementedError` with your code
4. Check yourself: `pytest 01-basics` (from the repo root)
5. Green = passed ✅. Red = read the error message, it's a clue, not a punishment

## Getting started

1. Follow [`00-setup`](00-setup/README.md) to install everything
2. Fork or clone this repo
3. Start with [`01-basics`](01-basics/README.md)
