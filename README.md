A welcoming, complete Python path for curious beginners around age 16. No programming experience is expected. Learn to reason through problems, write readable programs, and build small projects—not just memorize syntax.

## How to use this curriculum

Start with Tier 1 and move in order. Every concept folder contains an overview, a lesson, five exercises that increase in difficulty, and a separate answer guide. Try each exercise before checking answers. Predict output before running code and change one thing at a time.

- **Tier 1 — Basics:** environment, data, decisions, loops, collections, functions, files, and modules.
- **Tier 2 — Intermediate:** OOP, comprehensions, decorators, libraries, clean code, debugging, tests, APIs, and algorithms.
- **Tier 3 — Optional:** recursion, regex, concurrency, SQLite, scraping, and two capstone projects.

## Prerequisites

No coding experience or paid software is required. You need a computer where Python can be installed. Follow [SETUP.md](./SETUP.md) for Windows, macOS, and Linux. Examples target Python 3.10 or newer.

## Good learning habits

- Type examples instead of only reading them; predict the result first.
- Explain a problem in plain language before coding.
- Use a tiny input, then try a boundary case.
- Treat errors as clues and change one thing at a time.
- Take breaks; understanding beats rushing.
