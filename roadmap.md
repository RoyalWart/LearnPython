# Learning Roadmap

Estimates include reading and attempting exercises. Move at your own pace and revisit ideas when useful.

~~~text
Tier 1 — Basics (about 12–14 hours)
  Setup → data and text → decisions and loops → collections
  → functions and scope → errors and files → modules
                         ↓
Tier 2 — Intermediate (about 10–12 hours)
  OOP → comprehensions → decorators → libraries and environments
  → clean code → debugging and tests → APIs → algorithms
                         ↓
Tier 3 — Optional (about 8–10 hours)
  Recursion → regex → concurrency → SQLite → scraping
  → CLI capstone → Flask capstone
~~~
