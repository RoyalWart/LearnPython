# Comprehensions and Generator Expressions

**Tier 2 · Intermediate · about 50 minutes**

A comprehension builds a collection from an iterable; a generator yields values one at a time.

## In this module

A comprehension is a compact recipe; a generator is a dispenser that gives one item when asked.
